### [Prompt engineering udah mati — gantinya JSON Prompting](https://www.threads.com/@difathenextlevel/post/DfnuC-GjWCx)

Sumber: @difathenextlevel · diposting 11 Nov 2026 · disimpan via @mabrosid

**What:** Thread panjang (11 balasan author, semuanya berhasil ditarik) tentang JSON Prompting — menulis prompt sebagai JSON berisi pasangan key-value, supaya output AI tajam dan konsisten, bukan bahasa biasa yang hasilnya generik.

**Why:** Prompt bahasa biasa bikin model nebak-nebak — nada, panjang, audiens, sudut pandang — lalu dia mengisi semua celah dengan yang rata-rata secara statistik, dan itulah rasa generik yang tidak bisa dihilangkan. LLM tidak membaca prompt seperti manusia membaca surat; mereka mencocokkan pola dengan data latihannya, dan data latihan itu penuh kode, dokumentasi, API, dan skema — jadi JSON terasa akrab buat mereka dan dibaca sebagai instruksi yang lebih jelas.

**How:** Aturannya cuma tiga: 1) pasangan key-value, 2) tulis eksplisit, jangan sok pintar, 3) sarangkan objek (nest) kalau strukturnya penting. Tidak ada tool baru, tidak ada sintaks baru, dan bisa dipakai di model AI apa pun.

Contoh-contoh dari thread:

- Tweet biasa: "tuliskan tweet tentang detoks dopamin" → model nebak tone dan panjangnya. Versi JSON: `{"task": "tulis tweet", "topic": "detoks dopamin", "style": "viral", "length": "di bawah 280 karakter", "tone": "nendang, kontra-arus"}` — tidak ada ambiguitas, model berhenti menebak dan mulai mengeksekusi.
- Struktur bersarang: `{"task": "tulis thread", "platform": "x", "structure": {"hook": "bikin penasaran, di bawah 10 kata", "body": "3 insight dengan contoh", "cta": "pertanyaan yang memancing balasan"}, "topic": "produktivitas founder"}`.
- Cold email: `{"task": "tulis cold email", "audience": "founder SaaS", "product": "otomasi sales berbasis AI", "goal": "booking call 15 menit", "tone": "ramah tapi percaya diri", "length": "di bawah 90 kata"}`.
- Video demo aplikasi fitness: `{"task": "buat video", "video_type": "demo produk", "theme": "aplikasi fitness", "duration": "8 detik", "tone": "energik, elegan", "visual_style": "UI bersih, transisi cepat"}` — selisih hasilnya disebut tidak tipis.

Empat template plug-and-play (tinggal ganti nilainya, pertahankan strukturnya): 1) konten, 2) kode (Python — contohnya ganti nama semua file di satu folder, dengan constraints macOS + sertakan komentar), 3) strategi brand (bertindak sebagai konsultan brand, deliverables: 1 kalimat, target audiens, 3 pembeda), 4) tulis ulang (perbaiki tulisan jadi hidup dan emosional).

Pergeseran mindset yang ditekankan author: berhenti minta sesuatu ke AI, mulai tentukan persis apa yang lo mau — builder menyerahkan cetak biru, penyair melempar vibes. Bonusnya: prompt JSON gampang dirantai (output jadi input buat alur multi-langkah) dan gampang dipasang lewat API untuk automation. Ringkasnya: struktur = kejelasan = output lebih baik. Catatan: thread ini konten berbayar dari Netra Runtime (sponsor disebut di akhir thread, dan disebut sebagai salah satu opsi API yang kompatibel OpenAI dengan server di Indonesia).

Catatan dari komentar: ada yang kontra — satu komentator menilai ini kemunduran, karena AI agent justru memudahkan pemakaian bahasa natural, dan tanpa format JSON pun Claude atau agent lain sudah bisa mengerti. Meta AI menengahi: JSON prompting valid karena memaksa lo jadi eksplisit, tapi untuk chat sehari-hari bahasa natural yang terstruktur juga sama bagusnya; format disebut berpengaruh sampai 40% ke performa menurut studi yang dikutip Meta AI.

Terkait: [[2026-11-11]] — post "7 prompt ChatGPT buat rombak CV" di file itu adalah kumpulan prompt siap copas dengan tema yang sama (prompting).

Explore: ini bisa langsung dipakai di Gemini/Claude yang sudah dipakai sehari-hari — tanpa tool baru dan tanpa biaya. Coba ubah satu prompt yang sering dipakai (misalnya prompt buat Hermes, atau prompt buat nulis konten affiliate) ke format JSON dengan key task, audience, tone, dan format, lalu bandingkan hasilnya dengan versi bahasa biasa. Buat automation (bot Telegram, finance assistant), format JSON juga memudahkan parsing output — satu teknik, dua kegunaan.
