### [Bedah Postiz: scheduler media sosial open source yang bisa di-host sendiri](https://www.threads.com/@programmerbiasa/post/DfCY48YiX86)

Programmer Biasa membedah Postiz setelah mengulik selama satu jam. Postiz adalah tool scheduler media sosial yang 100% open source, bisa jalan di server sendiri, dan mendukung sampai 32 platform termasuk Threads. Kesimpulannya: tool ini bagus banget buat yang suka kontrol penuh, tapi bukan berarti cocok buat semua orang. ### [Vibe coding wajib ada 6 dokumen](https://www.threads.com/@_amrhba/post/De_8S-qmgLs)

Sumber: @_amrhba · diposting 27 Okt 2026 · disimpan via @mabrosid

Amrhba membagikan 6 dokumen yang wajib ada saat vibe coding, infonya dari YouTube Michael Kocher. Dia menekankan dokumen-dokumen ini tidak wajib secara mutlak, tapi amat digalakkan — karena tanpa dokumen, AI coding bekerja tanpa konteks yang jelas.

| No | Dokumen | Kepanjangan | Fungsinya |
|----|---------|-------------|-----------|
| 1 | PRD | Product Requirement Documentation | Apa yang harus dilakukan produk: kebutuhan dan fitur |
| 2 | TRD | Technical Requirement Documentation | Kebutuhan teknis: stack, arsitektur, batasan |
| 3 | AFD | App Flow Documentation | Alur aplikasi antar layar dan fitur |
| 4 | DBD | Design Brief Documentation | Brief desain: gaya visual dan komponen UI |
| 5 | BSD | Backend Schema Documentation | Skema backend: tabel, relasi, API |
| 6 | IPD | Implementation Plan Documentation | Rencana implementasi: tahapan pengerjaan |

Explore: buat project kecil, enam dokumen ini tidak harus enam file formal — cukup satu file konteks per dokumen di repo, atau bahkan satu file CONTEXT.md yang memuat keenam bagian secara ringkas. Kalau enam terasa berat, mulai dari PRD dan IPD dulu: PRD menjaga AI tidak salah membangun, IPD menjaga pengerjaan berurutan. Pola ini juga berlaku buat project non-koding, misalnya dokumentasi Brush Kart.

Terkait: 25 resource gratis buat bikin website pakai AI (bagian Teknologi & AI); penggunaan Claude Code paling keren (bagian ini juga).

### [Mulai ngonten tapi upload berkali-kali tidak ada yang nyangkut](https://www.threads.com/@caelishkids/post/DFcZko1vNeJ)

Sumber: @caelishkids · diposting 30 Jan 2025 · disimpan via @monggoditingali

Post ini menargetkan pemula ngonten yang sudah berkali-kali upload tapi tidak ada yang nyangkut. Penawaran author: akses +100 hook yang berpotensi bikin konten viral, dengan syarat komen "HOOK". Perlu dicatat jujur: isi tips tidak ada di post maupun di komentar — kolom komentar isinya author membagikan link akses yang sama berulang kali: https://lynk.id/caelish/LrGMXEg. Jadi nilai post ini adalah penawarannya, bukan tipsnya; isi di balik link itu belum diverifikasi.

Explore: hook itu cuma pembuka — yang bikin konten nyangkut tetap isi dan retensi setelah 3 detik pertama. Alternatif gratis tanpa link-gating: pelajari pola hook dari konten yang viral di niche sendiri (amati 3 detik pertamanya), lalu pakai formula yang sudah terbukti — pertanyaan tajam, pernyataan berani, atau hasil dulu baru proses. Dan waspada: penawaran "komen X untuk akses" seperti ini biasanya berujung funnel ke kelas berbayar, jadi perlakukan link-nya sebagai katalog, bukan jalan pintas.
