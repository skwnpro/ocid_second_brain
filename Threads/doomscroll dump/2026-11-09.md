### [Rate limiter + captcha wajib buat aplikasi vibe coding](https://www.threads.com/@heyrozx/post/DfgSU-6md6Z)

Sumber: @heyrozx · diposting 8 Nov 2026 · disimpan via @monggoditingali

**What:** Peringatan buat para vibecoder: aplikasi yang dibangun lewat vibe coding wajib dipasangi rate limiter dan captcha (disebut contohnya Cloudflare Turnstile) sejak awal, bukan setelah kejadian.

**Why:** Tanpa pembatas, siapa pun bisa membanjiri endpoint aplikasi berkali-kali — dan kalau endpoint itu memanggil API berbayar (mis. LLM), tagihannya bisa meledak karena ulah orang iseng. Biaya yang seharusnya kecil jadi "boncos" tanpa disadari.

**How:** Pasang rate limit di endpoint yang mahal (terutama yang memanggil model AI atau API pihak ketiga) dan pasang captcha di form atau endpoint publik supaya request otomatis dari bot ketahan. Cloudflare Turnstile disebut sebagai opsi captcha yang ringan dan tidak mengganggu pengguna seperti captcha gambar.

Explore: ini langsung nyambung ke setup user sendiri — bot Telegram dan layanan di VPS juga punya permukaan yang sama: endpoint publik tanpa pembatas adalah undangan buat disalahgunakan. Buat web app di VPS, rate limit bisa dipasang gratis di level reverse proxy (Caddy/Nginx) atau middleware framework, plus Cloudflare free tier di depan; buat bot Telegram, batas per user per menit sudah cukup menahan banjir. Turnstile sendiri gratis untuk pemakaian wajar, jadi tidak ada alasan menunda proteksi ini sampai tagihan jebol duluan.
