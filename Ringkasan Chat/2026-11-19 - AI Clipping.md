# AI Clipping

Ringkasan 19 November 2026 — di WhatsApp (~18:06 WIB): user membagikan satu reel Facebook soal peluang clipping konten GTA 6, dan Bre membedahnya — termasuk peringatan copyright-nya.

## Reel-nya: GTA 6 rilis, streamer live berjam-jam (18:06)

- User membagikan reel dari **Sultan Rap**: GTA 6 sudah rilis, streamer besar pada live berjam-jam, dan dia bilang ini peluang cuan buat yang mau memotong-motong momen seru dari live itu jadi video pendek terus upload.
- Sumber: reel Facebook (link dibagikan user di chat). Isi reel diringkas dari penjelasan Bre di chat — klaim-klaim di dalamnya **belum terverifikasi**.

## 3 tool AI clipping gratis yang disebut di reel

- **OpenShorts** — open source: lempar video panjang, AI-nya mencari momen viral lalu menjadikannya klip vertikal + judulnya.
- **AutoClip** — juga open source di GitHub: masukkan link video panjang, dia menandai highlight-nya, user tinggal pilih.
- **AI Shorts Generator** — alternatif gratisnya Opus Clip: mencari highlight, memberi subtitle, auto-crop vertikal, tanpa watermark.
- **Belum terverifikasi:** link asli ketiga tool itu **tidak ada di reel** — kreatornya menyuruh komen "Clipping" dulu baru dikirim. Bre menawarkan untuk mencarikan link aslinya; user belum menjawab. Jangan anggap ketiga tool ini sudah dicek — nama dan klaimnya hanya dari reel.

## Catatan jujur Bre: rawan copyright

- Bre mengingatkan: clipping live streamer orang lain lalu upload ulang itu **rawan copyright/strike, apalagi konten GTA 6**. Bedanya dengan konten lifehack user: bahan lifehack itu dari user sendiri.
- Ini nyambung dengan **ide clipper (#6)** dari brainstorming user — ide yang sekarang **on hold** karena proyek SATU yang sedang jalan adalah konten lifehack → affiliate (lihat [[2026-11-17 - Konten Lifehack]]). Reel ini belum mengubah status itu: user baru membagikan, belum memutuskan apa-apa.

## Langkah berikut

- Kalau user mau, Bre bisa mencarikan link asli ketiga tool itu — tawaran ini masih terbuka, belum dijawab.
