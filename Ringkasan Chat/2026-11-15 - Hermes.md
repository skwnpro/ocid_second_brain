# Hermes

Ringkasan 15 November 2026 — dua pekerjaan Hermes dalam satu malam, masih di side chat "Choose OS for 4GB laptop server" (00:52–01:54 WIB): gateway Telegram di G480 akhirnya nyambung setelah perbaikan 401, lalu Hermes di VPS dibersihkan total dan di-install ulang dengan model gratisan.

## G480: gateway Telegram dan perbaikan 401

- **Bot Telegram dibuat dulu (Batch 1).** User membuat bot lewat @BotFather di HP, dapat tokennya ("udah dapet api botnya") — token tidak dikirim ke chat. Asisten memandu: token dimasukkan lewat `hermes gateway setup` (perintah interaktif), bukan diketik sebagai bagian perintah shell supaya tidak tersimpan di history terminal. Cek `grep telegram ~/.hermes/config.yaml` menunjukkan config belum ada bagian Telegram-nya sama sekali — memang harus lewat `setup`.
- **User lalu minta diambil alih ("bre ambil alih aja pusing udah gw, benerin")** karena `hermes -z "2+2"` gagal: `custom rejected your API key`, HTTP 401 Invalid API key.
- **Penyebab 401 ketemu:** kunci 9Router di `~/.hermes/.env` ditempel **pakai kurung siku `< >`** di depan-belakangnya (`NINE_ROUTER_API_KEY` dan `OPENAI_API_KEY`), jadi Hermes mengirim kunci yang salah. Kurungnya dibuang, tes `hermes -z "jawab dengan satu angka saja: 2+2, tanpa penjelasan"` keluar `4`. Gateway di-restart, log menunjukkan `Model context warmed: gemini/gemini-3.6-flash -> 1048576 tokens` — Hermes G480 → 9Router → Gemini sudah nyambung.
- **Daftar kesalahan user malam itu** (diminta user, dikirim ke chat): (1) Batch 1 dijalankan di PC, bukan di G480; (2) SSH tunnel dijalankan di G480 ke dirinya sendiri, akibatnya port 20128 + 9119 `Address already in use` lalu `Too many open files` — tunnel itu harusnya dijalankan di PC; (3) typo perintah dashboard, `hermes dashboard --port 9119 -- host 127.0.0.1` (ada spasi, yang benar `--host` nempel); (4) tempel kunci API pakai `< >` — kurung di contoh itu cuma penanda placeholder; (5) kirim screenshot hotspot yang password-nya kelihatan — lain kali ditutup/blur dulu.

## VPS: Hermes dibersihkan total, install ulang dengan model gratis

- **Permintaan user:** bot Telegram VPS yang dulu di-setup pakai Cue AI terasa tidak bersih — bersihkan Hermes juga, biar sebersih G480. Empat jawaban user: (1) bot Telegram dibiarkan saja, nanti tokennya dipakai ke gateway/agent baru; (2) hapus Hermes lalu setup baru tersambung ke 9Router, **tanpa Gemini** (API key-nya sudah dihapus user), cari model gratisan; (3) setup supaya dapat model gratisan, respons lama tidak apa-apa yang penting jalan gratis; (4) bot finance jangan disentuh.
- **Backup dulu sebelum hapus:** `~/.hermes` → `~/.hermes.bak-2026-11-15` (3,1 GB), isinya config lama + token bot Telegram + `auth.json` (Nous OAuth) — token bot aman untuk dipakai lagi nanti.
- **Dihapus:** `hermes-gateway.service` (stop, disable, uninstall), install + config Hermes lama, dan satu proses dashboard lama yang masih menahan port 9119. Bot finance, kode finance, dan database **tidak disentuh**.
- **Install ulang bersih: Hermes Agent v0.23.1** (2026.9.24) via installer resmi, sama seperti install bersih di G480. Hanya `auth.json` (Nous OAuth) yang dikembalikan dari backup.
- **Tidak ada model gratis yang jalan lewat 9Router.** Subagent mengetes semua 26 model di katalog 9Router lewat `http://127.0.0.1:20128/v1/chat/completions`: NVIDIA (deepseek-v4-flash/pro, minimax-m2.7/m3, glm-5.2) → HTTP 410 end-of-life; kimi-k2.6/nemotron → 503/404; OpenCode `oc/*-free` → 429 (kuota gratis habis); muse-spark/union-alpha → 400; jev-1.13-free → 400; mmf/mimo-auto → 502.
- **Dipakai sekarang: Hermes langsung ke Nous Portal Free, model `upstage/solar-mini4:free`** — itu yang dulu dipakai VPS sebelum pindah ke Gemini, dan OAuth Nous-nya masih hidup (akun `skwn.pro@gmail.com`), jadi tidak perlu kunci/akun baru. Tes end-to-end dua kali: `hermes -z "2+2"` keluar `4`, ~12 detik.
- **9Router tetap jalan (v0.5.116, service aktif).** Provider Gemini dimatikan sesuai perintah (kedua baris `providerConnections` di-set `isActive=0`), katalog 26 → 17 model. Kunci 9Router `hermes` masih ada di DB tapi sudah tidak dipakai Hermes.
- **Yang masih perlu user lakukan:** gateway Telegram VPS belum jalan — service lamanya sudah dihapus. User tinggal `hermes gateway setup` di VPS, masukkan token bot lama (ada di backup), lalu `hermes gateway install --system`.
- **Bot finance tidak disentuh dan tetap aktif** (`cashflow-bot` + `advisor-bot`, aktif sejak 2026-10-29).

## Dua hal yang perlu diluruskan / ditindaklanjuti

- **Gemini lewat 9Router ternyata masih hidup saat dites** (balik HTTP 200 sebelum dimatikan) — kemungkinan kunci yang user hapus itu kunci yang lain (misal kunci finance bot), bukan kunci yang dipakai 9Router. Gemini tetap dimatikan sesuai perintah; kalau mau dinyalakan lagi, tinggal flip satu flag di DB 9Router.
- **Peringatan keamanan — kunci bocor, harus diganti.** Saat diagnosa, subagent tidak sengaja mencetak materi rahasia lengkap ke log: **kunci API NVIDIA lengkap dan token OAuth Nous (access + refresh) lengkap**. Token bot Telegram dan kunci 9Router `hermes` tidak kena (hanya prefix-nya). Yang harus dilakukan: (1) regenerate kunci NVIDIA di build.nvidia.com; (2) di VPS jalankan `hermes auth add nous` untuk token Nous baru (yang lama di-revoke kalau bisa). **Belum terverifikasi apakah rotasi ini sudah dilakukan user.**
