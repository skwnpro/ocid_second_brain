## G480 vs STB B680H buat VPS (10:54 WIB)

- **Verdict: buat jadi VPS utama, G480 menang.** STB B680H menangnya cuma di listrik sama ukuran.
- **Cost:** G480 Rp0 — sudah punya dan sudah jalan (Ubuntu + 9Router + Hermes + dashboard semua sudah kepasang). STB B680H V5 bekas sekitar Rp390rb di Tokopedia (yang ori + dus), HG680P yang sekelas malah Rp230–310rb — belum termasuk microSD/flashdisk buat storage tambahan. Listrik (tarif PLN ~Rp1.444/kWh, hitungan kasar): STB cuma 3,5–5,5 watt → sekitar Rp5rb/bulan; G480 laptop kira-kira 15–25 watt → sekitar Rp20–30rb/bulan. Jadi STB hemat ~Rp15–25rb/bulan, sekitar Rp200–300rb setahun. Biaya wifi-nya sendiri sama saja buat dua-duanya.
- **Performa:** G480 Core i3/i5 generasi 2–3 (2 core/4 thread, TDP 35W), RAM bisa naik sampai 8GB, x86 jadi semua software tinggal install — 9Router, Hermes, OpenCode, Docker, semua ada build-nya. B680H: Amlogic S905X, 4 core Cortex-A53 1,5GHz, RAM 2GB mentok (nggak bisa nambah), storage eMMC 8GB. Buat Hermes + 9Router + bot finance sih cukup — ada yang sudah membuktikan Hermes jalan di STB 2GB, RAM kepake ~700MB — tapi mepet, nggak ada ruang buat nambah-nambah. 9Router sendiri ada build ARM64 (Docker multi-platform linux/arm64), jadi bisa, tapi belum pernah dicoba di ARM. LAN: dua-duanya Fast Ethernet 100Mbps saja — G480 juga 10/100M menurut spek resminya.
- **Keandalan:** G480 titik lemahnya HDD 2012 (umur 14 tahun, ini risiko rusak paling besar) sama kipas. Plusnya: ada layar + keyboard nempel, jadi kalau ada apa-apa gampang ditolongin langsung. Satu catatan: RAM G480 kebaca cuma ~1,7GB di dashboard, padahal speknya 4GB — stiknya perlu dicek dulu, siapa tahu satu stik mati. STB: nggak ada kipas, nggak ada HDD, jadi secara fisik lebih bandel buat nyala 24/7. Titik lemahnya: eMMC 8GB itu sempit (abis install Armbian sisa ~4,5–5,2GB) dan flash gampang aus kalau log/swap numpuk di situ — perlu storage USB tambahan. Terus install awal Armbian di S905X ada jebakan bootloader-nya, bukan sekali jalan.
- **Satu hal penting:** dengan wifi rumah kepasang, kelemahan terbesar G480 selama ini (tethering hotspot HP + driver WiFi Broadcom yang rewel) hilang. Tapi buat server, **colok kabel LAN, jangan pakai WiFi** — mau G480 atau STB sama saja.
- **Saran Bre:** G480 tetap jadi VPS utama — nol kerja migrasi, performa lebih lega, bisa di-upgrade (tambah RAM ke 8GB + ganti HDD ke SSD SATA, itu satu-satunya upgrade yang benar-benar ngaruh ke keandalan). Kalau tetap beli STB, jadiin node kedua yang ringan: Pi-hole/AdGuard + WireGuard + broker MQTT buat monitoring hidroponik ESP32 nanti. Besok fokus pasang wifi + kabel LAN ke G480 dulu. STB itu nice-to-have, bukan pengganti.
- Keputusan beli STB masih terbuka — user belum memutuskan.
