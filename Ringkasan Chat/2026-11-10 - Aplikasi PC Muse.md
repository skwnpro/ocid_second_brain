# Aplikasi PC Muse

Ringkasan 10 November 2026 — ketersediaan aplikasi desktop Muse buat PC user (main chat, 16:30 WIB).

## Yang ada sekarang

- **Mac:** ada aplikasi resmi, download di ai.meta.com/muse/download.
- **Windows / Linux (termasuk PC Ubuntu user):** tidak ada aplikasi native — pakainya web di muse.ai, sama seperti yang dibuka sekarang.
- **HP:** ada, iOS dan Android.

## Rilis Linux: belum ada tanggal

- User bertanya kapan rilis buat Linux (16:31 WIB). Jawabannya: **belum ada tanggalnya, bahkan belum diumumkan.** Microsoft bilang 7 Oktober 2026 aplikasi Windows native "coming soon" tapi tanpa tanggal; buat Linux, Meta belum mengumumkan apa-apa soal aplikasi native. Ini status saat ditanya, belum terverifikasi ada perubahan sesudahnya.
- **Jalan pintas sementara di Ubuntu:** buka muse.ai di Chrome, lalu install sebagai web app (menu Chrome → "Install app" / "Save and share" → "Create shortcut"). Jadinya kebuka di jendela sendiri tanpa tab dan address bar, rasanya seperti aplikasi beneran.
